# 🐭 litmouse diary bot

Telegram-бот блога **litmouse diary**: гайды по городам, анонимные вопросы, отзывы и ссылки на соцсети — всё в одном месте.

Канал: [@litmouseee](https://t.me/litmouseee) · Instagram: [litmouse](https://www.instagram.com/litmouse) · TikTok: [@litmouse.diary](https://www.tiktok.com/@litmouse.diary)

---

## ✨ Возможности

### Для пользователей
- **🌍 Гайды по городам** — PDF/файлы с гайдами выдаются после подписки на канал. Если гайд ещё не готов, можно нажать «🔔 Сообщить о выходе» — бот сам напишет, когда он появится.
- **❓ Анонимные вопросы** — вопрос уходит автору без имени отправителя. Ответ приходит лично или публикуется в канале вместе с вопросом. Между вопросами действует пауза 3 минуты, чтобы не было спама.
- **⭐ Отзывы** — оценка от 1 до 5 и текст, можно оставить анонимно или с ником.
- **📱 Соцсети** — быстрые ссылки на Instagram, Telegram и TikTok.

### Для админов
- **📊 Статистика** — пользователи, открытия меню, скачивания гайдов, вопросы, лист ожидания.
- **🗂 Управление гайдами** — добавление и замена гайдов прямо из чата, без правок кода. После загрузки гайда все из листа ожидания получают уведомление.
- **❓ Ответы на вопросы** — с предпросмотром и выбором: опубликовать в канал или ответить только лично.
- **📣 Рассылка** всем пользователям с подтверждением перед отправкой.

## 🛠 Команды админа

| Команда | Что делает |
|---|---|
| `/admin` | Открыть админ-меню |
| `/stats` | Показать статистику |
| `/broadcast текст` | Рассылка всем пользователям |
| `/addguide city_key Название` | Добавить или заменить гайд (затем отправить файл) |
| `/questions` | Последние анонимные вопросы |
| `/feedback` | Отзывы и средняя оценка |
| `/cancel` | Отменить текущий ввод |

Пример добавления гайда:
```
/addguide paris 🇫🇷 Париж
```
После этого бот попросит прислать файл.

## 🚀 Запуск

### 1. Установка
```bash
git clone https://github.com/Q7N3T/litmouse-bot.git
cd litmouse-bot
pip install -r requirements.txt
```

### 2. Переменные окружения

| Переменная | Обязательна | Описание |
|---|---|---|
| `BOT_TOKEN` | ✅ | Токен бота от [@BotFather](https://t.me/BotFather) |
| `WEBHOOK_URL` | — | Публичный адрес сервера. Если задан — бот работает через webhook, иначе через polling |
| `WEBHOOK_PATH` | — | Путь для webhook (по умолчанию `telegram`) |
| `PORT` | — | Порт веб-сервера (по умолчанию `10000`) |
| `STATS_DB_PATH` | — | Путь к базе SQLite (по умолчанию `/var/data/bot_stats.db`, если папка есть, иначе `bot_stats.db`) |

### 3. Старт
```bash
export BOT_TOKEN="ваш_токен"
python botprof.py
```

> ⚠️ Бот должен быть **администратором канала**, указанного в `CHANNEL_USERNAME`, — иначе он не сможет проверить подписку для выдачи гайдов.

### Настройка под себя
В начале `botprof.py`:
- `ADMIN_IDS` — Telegram ID админов
- `CHANNEL_USERNAME` — канал, на который нужно подписаться для получения гайдов

---

## ☁️ Деплой

Бот рассчитан на хостинги вроде Render / Railway:
- Start command: `python botprof.py`
- Задайте `BOT_TOKEN` и `WEBHOOK_URL` в переменных окружения
- Подключите постоянный диск в `/var/data`, чтобы база не терялась при перезапуске

---

## 🔒 Безопасность

Токен и другие секреты **не хранятся в репозитории** — только в переменных окружения на сервере. Файлы `.env` и `*.db` добавлены в `.gitignore`.
